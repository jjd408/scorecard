Scorecard is a desktop app for keeping a baseball scorecard at-bat by at-bat. Each installer includes its own
Java, so nothing else needs to be installed.

## Install

| System | Download | How |
| --- | --- | --- |
| Windows 10/11 | `Scorecard-*.msi` | Run it. Windows may warn that the publisher is unknown: choose **More info**, then **Run anyway**. Scorecard appears in the Start menu. |
| macOS (Apple Silicon) | `Scorecard-*.dmg` | Open it and drag Scorecard to Applications. The first time, right-click the app and choose **Open**, since it isn't signed by Apple. |
| Linux (Debian, Ubuntu, MX) | `scorecard_*_amd64.deb` | `sudo apt install ./scorecard_*_amd64.deb`. Scorecard appears in the applications menu. |

Your teams, players and games are saved in `.scorecard/scorecard.db` in your home folder, and stay there when
you upgrade or uninstall. Press **F1** or click **Help** in any window for the manual.
